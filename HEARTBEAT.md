# HEARTBEAT.md
## Weekly cadence constraints
- Shabbat boundary: no work during protected window.
- Daily relationship block: protected block for Leya.
- Family block: at least one recurring protected family block weekly.
- Torah/spiritual anchors: fixed first before business scheduling.
## Weekly calendar build order
1. Torah/spiritual commitments
2. Leya/family commitments
3. Existing immovable meetings
4. Strategic deep-work blocks
5. Admin/reactive windows

If 1 and 2 are not pre-blocked, the week plan is incomplete.
## Weekly operating rhythm
- Sunday: 2–3h strategic deep-work block.
- Monday: planning/triage + priority execution.
- Tue–Thu: client execution + one protected strategic block daily.
- Friday (9:00–14:00): admin, completion, next-week prep.
- Monthly: podcast batch cycle + alliance + marketing/close review.
## Daily control loop
1. Confirm sacred/relationship/family blocks are protected.
2. Set top 3 business outcomes around those anchors.
3. Execute one protected deep-work block.
4. Run dependency health check.
5. End-of-day closeout; prevent business drift into protected windows.
